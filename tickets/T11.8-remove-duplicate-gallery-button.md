# T11.8 — Remove the duplicate Gallery button

## Goal

Every creator page should show **one** Gallery action. The creator header
currently renders two identical buttons.

## Problem

`src/monoke/web/templates/creator.html` has the same link twice in
`creator-actions`:

```html
<a class="button" href="/c/{{ creator.id }}/gallery">Gallery</a>
<a class="button" href="/c/{{ creator.id }}/gallery">Gallery</a>
```

That produces two adjacent Gallery buttons on `/c/{id}`. At narrow widths they
wrap and look like separate, equally important actions.

Other surfaces are not duplicated:

- the dashboard shows one Gallery button per creator card;
- the gallery header shows **Open viewer / Posts / Links**;
- breadcrumbs are links, not action buttons.

## Scope

- [ ] Remove the duplicate anchor from `creator.html`, keeping one Gallery
      action.
- [ ] Keep the action order predictable: **Gallery**, **Sync**, **Delete**.
- [ ] Do not change labels, styling or destinations of the remaining actions.
- [ ] Add a regression test that renders `/c/{id}` and asserts exactly one
      `href="/c/{id}/gallery"` action labelled **Gallery**.
- [ ] Add a light page-level check that no other rendered page shows more than
      one Gallery action button, so a future include cannot reintroduce it.
- [ ] `uv run pytest` passes.

## Acceptance criteria

- [ ] `/c/{id}` has exactly one Gallery button in the header.
- [ ] The remaining Gallery button still opens `/c/{id}/gallery`.
- [ ] Dashboard, gallery and bookmarks pages are unchanged.
- [ ] No duplicate button reappears at 390 px or in fullscreen layouts.

## Out of scope

- Navigation or action-bar redesign.
- Renaming Gallery to Media or changing its route.
- Dashboard card layout changes.

## Notes

- The duplicate looks accidental (a copy/paste), not a second intended action.
  If it was meant to be a different destination, file a new ticket instead of
  keeping two identical buttons.
