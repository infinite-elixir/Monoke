# T12.5 — Move cum.st behind the source adapter with zero behaviour change

## Goal

Prove the adapter seam on the existing source before pawchive is added. cum.st
must produce byte-identical posts, files, links and URLs after the refactor.

## Scope

- [ ] Implement `sources/cumst/adapter.py` using the T12.2 protocol:
      - [ ] URL builders and API paths equivalent to today's
            `cumst/urls.py`.
      - [ ] `parse_profile`, `parse_posts_page`, `parse_post` wrapping the
            existing pydantic models.
      - [ ] `creator_images` using the existing `img.cum.st` rules.
      - [ ] `image_hosts() -> {"img.cum.st"}` for caption sanitizing.
      - [ ] `posts_params(offset, page_size)` emits
            `o, n, compact=1, sort=recent` exactly as today.
- [ ] Keep `cumst/media.py` as the cum.st-specific URL builder; expose it
      through the adapter rather than importing it from `extract/`.
- [ ] Make `CumstClient` use the adapter for endpoint paths and payload parsing
      while using the shared transport from T12.4.
- [ ] Route `crawler/crawl.py` and `web/tasks.py` through the registry for
      cum.st URLs; keep the same progress events and CLI output.
- [ ] Leave `sources/__init__.py` exporting the registry only.

**Regression proof**

- [ ] Golden test: crawl the existing cum.st fixtures and compare the resulting
      `posts`, `files`, `links`, `tags`, captions and source URLs before/after.
      A simple snapshot of the DB rows is enough.
- [ ] Assert media URLs are still
      `https://e{1,2,3}.cum.st/media/{sha}/...` and thumbnails still
      `https://img.cum.st/thumbnail/{sha}/preview.webp`.
- [ ] Existing `tests/test_client.py`, `test_crawl.py`, `test_urls.py`,
      `test_media.py`, `test_extract*`, `test_web.py` pass without fixture edits.
- [ ] A live cum.st smoke test is optional and stays behind `MONOKE_LIVE=1`.

## Acceptance criteria

- [ ] `monoke sync https://cum.st/creators/patreon/274608` behaves exactly as
      before (same request count, same rows, same outputs).
- [ ] No `cumst` import remains in the crawler, extractor or web routes except
      through the registry/adapter.
- [ ] The adapter is the only place a cum.st host or path fragment appears.
- [ ] `uv run pytest` is green offline.

## Out of scope

- Pawchive (T12.6+).
- UI copy and source badges (T12.9).

## Notes

- Resist "while I'm here" changes. This ticket is a pure seam refactor; behaviour
  differences belong in T12.6–T12.9.
