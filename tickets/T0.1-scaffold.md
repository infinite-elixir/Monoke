# T0.1 — Project scaffold and configuration

## Goal
A runnable skeleton: `uv` project, package layout, config, CLI entrypoint, FastAPI app that
boots and serves a health route.

## Scope

- [ ] `uv init` with Python 3.14, `src/` layout.
- [ ] Dependencies: `fastapi`, `uvicorn[standard]`, `httpx`, `jinja2`, `beautifulsoup4`, `lxml`,
      `nh3`, `python-multipart`, `pytest`, `pytest-asyncio`, `respx`.
- [ ] `pyproject.toml` console script: `monoke = "monoke.cli:main"`.
- [ ] Package tree from PLAN §4 (empty modules are fine).
- [ ] `config.py`:
      - `data_dir` (default `./data`, override `MONOKE_DATA_DIR`), `db_path`
      - `host=127.0.0.1`, `port=8765`
      - `api_base="https://cum.st/api/v1"`
      - `site_base="https://cum.st"`
      - `img_base="https://img.cum.st"`
      - `edge_hosts=["https://e1.cum.st","https://e2.cum.st","https://e3.cum.st"]`
      - `concurrency=4`, `page_size=50`
      - `user_agent="Monoke/0.1 (local private archive)"`
- [ ] `cli.py` with `serve`, `sync`, `db` subcommands via argparse (no extra deps).
- [ ] FastAPI app factory `create_app()`; `GET /healthz` → `{"ok": true, "version": ...}`.
- [ ] `.gitignore`: `data/`, `.venv/`, `__pycache__/`, `*.db`, `.pytest_cache/`.
- [ ] `README.md` stub with run instructions.

## Acceptance criteria

- [ ] `uv sync` completes on a clean checkout.
- [ ] `uv run monoke --help` lists `serve`, `sync`, `db`.
- [ ] `uv run monoke serve` starts and `curl 127.0.0.1:8765/healthz` returns 200 JSON.
- [ ] `uv run pytest` runs (0 tests is acceptable at this point).
- [ ] No import of `requests`, `selenium`, `playwright`, or any browser driver.

## Notes
- No special request headers are needed for cum.st — do not copy kemono's `Accept: text/css`
  workaround into this codebase.
- Config must be importable without side effects so tests can override paths.
