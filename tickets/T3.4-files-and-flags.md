# T3.4 — Attachments, media URLs, tags

## Goal
Represent every attachment with usable URLs and full metadata, deduplicated and honest about
what exists.

## Scope

- [x] `cumst/media.py` builders:
      - `ext_for(attachment)` — extension from `originalFilename`, else
        `gif→gif, video→mp4, audio→m4a, file→bin, image→jpg`.
      - `edge_host(sha256)` — deterministic: `edge_hosts[int(sha256[0], 16) % 3]`.
      - `media_url(sha256, name)` → `{edge}/media/{sha}/{name}`
      - `original_url(attachment)` → `media_url(sha, "original." + ext)`
      - `variant_urls(attachment)` → `[{name, url}]` for `original.mp4`, `720p.mp4`, `240p.mp4`
      - `thumb_url(sha256)` → `https://img.cum.st/thumbnail/{sha}/preview.webp`
      - `creator_images(profile)` → avatar/header/header-full with `?v={updated}`
- [x] `extract_files(post_detail) -> list[FileRow]` from `attachments[]`:
      `sha256, kind, mimeType, bytes, storageKey, variants_json, width, height, durationMs,
      originalFilename, url, thumb_url, position`.
- [x] Deduplicate by `sha256` within a post (the API repeats identical attachments); keep the
      lowest `position`.
- [x] A post with `attachments: []` is simply "no attachments" (no dead-file concept exists on
      this site).
- [x] Tags: `post.tags[{slug,label}]` → `tags` table, keyed by slug.
- [x] `caption_text`: plain text from parsed `captionHtml`, entities decoded, whitespace
      collapsed, used for search.
- [x] `sanitize_html(captionHtml) -> str` via `nh3` (fallback: bs4 allowlist):
      allow `p, br, a, strong, b, em, i, u, s, ul, ol, li, blockquote, code, pre, img,
      h1–h4, table, thead, tbody, tr, td, th, span, div`;
      allow `href, src, alt, title, class, target, rel, referrerpolicy`;
      force `rel="noopener noreferrer nofollow"` and `target="_blank"` on links;
      strip `script/style/iframe/object/embed/form` and all `on*` attributes.

## Acceptance criteria

- [x] `post_172189145` → 1 file: `image/jpeg`, 109987 bytes, `original.jpg`,
      URL `https://e{1,2,3}.cum.st/media/827766…/original.jpg`, thumb
      `https://img.cum.st/thumbnail/827766…/preview.webp`.
- [x] `post_151983862` → 1 file (`gif`, `original.gif`, 14432 bytes expected), not marked
      missing, and the URL returns 206 in a live test.
- [x] `post_171430071` → gif file with a working `thumb_url`.
- [x] Duplicate attachment in a synthetic payload collapses to one row.
- [x] `post_172189145` tag → `("public-model-release", "Public Model Release")`.
- [x] A caption with `<script>` and `onclick=` renders clean.
- [x] `caption_text` contains no HTML tags and preserves the prose.

## Notes
- Never build media URLs from `storageKey` — the edge path uses `sha256`.
- The site randomizes edge hosts; we use a deterministic host so links and tests are stable.
- Video posts are rare for the reference creator; test the builder with a synthetic video
  attachment (`kind="video"`, variants `original.mp4/720p.mp4/240p.mp4`).
