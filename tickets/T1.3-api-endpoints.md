# T1.3 — API endpoints and models

## Goal
Typed wrappers for the three calls that matter, matching the live payloads.

## Scope

**Models**

```python
CreatorProfile(id, name, service, displayName, avatarThumbhash, headerThumbhash,
               indexed, updated, contentUpdated, bookmarked, hasTags, gender)

PostSummary(id, service, title, captionText, added, published, bookmarked,
            attachments: list[SummaryAttachment])

SummaryAttachment(position, id, sha256, kind, originalFilename,
                  width, height, durationMs, previewThumbhash)

PostDetail(id, service, caption, captionHtml, title, added, published,
           attachments: list[Attachment], links, tags, prev, next,
           creator, linked, revisions)

Attachment(position, id, sha256, kind, mimeType, bytes, storageKey,
           variants: list[Variant], originalFilename, width, height, durationMs,
           previewThumbhash)

Variant(name, bytes)
Tag(slug, label)
```

**Methods**

- [x] `async profile(ref) -> CreatorProfile`
- [x] `async posts_page(ref, offset, *, sort="recent", q=None, tag=None)
      -> PostsPage(total:int, posts:list[PostSummary])`
- [x] `async post(ref, post_id) -> PostDetail`
- [x] `posts_page` always sends `n=50&compact=1` and validates the response has `total` and
      `posts`; `n` is capped server-side, so assert `len(posts) <= 50` only.
- [x] Handle: `attachments: []`, `caption: null`, `captionHtml: null`, `tags: []`,
      `prev/next: null`, `links: []`, `revisions: []`. Ignore `comments` entirely.
- [x] Return the raw payload alongside the model for persistence.

## Acceptance criteria

- [x] `posts_274608_o0.json` → `total == 782`, `len(posts) == 50`.
- [x] `posts_274608_o780.json` → 2 posts; `posts_274608_empty.json` → 0 posts, total 782.
- [x] `post_172189145.json` → 1 attachment (`image/jpeg`, 109987 bytes,
      `variants[0].name == "original.jpg"`), 1 tag, `captionHtml` contains
      `target="_blank"`.
- [x] `q="overwatch"` and `tag="public-model-release"` pass through as query params.
- [x] Live smoke: `total == 782`, `sort="top"` does not crash, `sort="popular"` is never emitted.

## Notes
- No separate profile `post_count`: use `total` from a list response.
- Comments/revisions are returned in the payload; store counts only, never the bodies.
