# T11.12 — Fullscreen control is available in the viewer opened from Bookmarks

## Goal

The viewer opened from `/bookmarks` must expose the same **fullscreen** control
as the gallery viewer. Today the fullscreen button is missing in the bookmarks
context, so a bookmarked image or video cannot be expanded to browser
fullscreen from the library.

## Reported behaviour

- Open `/bookmarks?view=media`.
- Click a media bookmark to open the merged viewer.
- The bottom control bar has no fullscreen button; the same overlay opened from
  a gallery does.

## Expected behaviour

- The bookmarks viewer bar shows the fullscreen icon beside the other controls.
- It enters and exits browser fullscreen exactly like the gallery viewer.
- Its icon/label switches between **Enter fullscreen** and **Exit fullscreen**
  with `aria-pressed`, and the state survives prev/next navigation.
- Keyboard `f` (if bound) and Escape behave the same in both contexts.

## Investigation notes

- Both pages include the same `partials/lightbox.html`, so first confirm whether
  the button is absent from the rendered DOM, hidden by CSS, or clipped by the
  control bar.
- Check context-specific visibility/state in `lightbox.js`, especially the
  bookmarks playlist path from T11.10 (longer "N of M bookmarks" counter and
  disabled post buttons).
- Check the bar's `flex-wrap: nowrap` layout: the longer bookmarks counter plus
  the action icons must not push or clip the fullscreen control, especially on
  narrow viewports.
- Do not introduce a second overlay or a bookmarks-only control bar.

## Scope

- [ ] Reproduce on `/bookmarks` and identify the exact cause (missing markup,
      conditional hide, overflow/clipping, or JS removal).
- [ ] Make the fullscreen control render and remain reachable in the bookmarks
      viewer without changing gallery behaviour.
- [ ] Keep the control bar one row; allow the counter to truncate/ellipsis
      rather than overflow if space is tight.
- [ ] Preserve focus order and accessible name; the button must be keyboard
      reachable.
- [ ] Update or add a test asserting the fullscreen control is present and
      visible in the bookmarks viewer.

## Acceptance criteria

- [ ] Opening the viewer from `/bookmarks` shows the fullscreen button.
- [ ] Clicking it enters and exits browser fullscreen as expected.
- [ ] The gallery viewer's fullscreen control is unchanged.
- [ ] `node --check src/monoke/web/static/lightbox.js` and `uv run pytest` pass.
