# T4.1 — App shell, templates, static assets

## Goal
One layout, one stylesheet, one JS file. No build step, no CDN.

## Scope

- [ ] Jinja2 templates: `base.html`, `_macros.html` (badge, link-row, paginator, empty-state),
      `partials/`.
- [ ] `base.html`: header (logo "Monoke", nav: Creators · Links), flash/error slot,
      content block, footer with data-dir + last sync.
- [ ] `static/style.css`: system font stack, CSS variables for dark/light, responsive grid,
      category badge colors (drive=green, mega=red, direct_media=blue, video_host=purple,
      shortener=amber, other=grey), no-attachments styling.
- [ ] `static/app.js`: theme toggle (`localStorage`), NSFW blur toggle (`localStorage`),
      copy-to-clipboard helper, htmx hooks.
- [ ] Vendor `htmx.min.js` into `static/` (commit it; no CDN).
- [ ] Base routes: `GET /healthz`, `GET /` placeholder, 404 template, 500 template.
- [ ] Static files mounted; cache-busting via `?v=` query from a constant.

## Acceptance criteria

- [ ] `/` renders, `/static/style.css` returns 200, page works with the network disabled.
- [ ] Theme toggle persists across reloads.
- [ ] Blur toggle applies `.nsfw` class to `img.thumb` and persists.
- [ ] No external requests from any template (no Google Fonts, no unpkg).
- [ ] 404 returns the template with status 404, not a traceback.

## Notes
- Keep it plain: server-rendered HTML + htmx. Any component logic that needs JS goes in
  `app.js`, not inline.
