# T6.3 — Page performance: browser extensions warn of slowdown

## Goal
Zen reports uBlock Origin and Proton Pass are "slowing the browser down" on Monoke but not on other sites. Investigate layout/paint cost and heavy DOM.

## Scope
- [x] Profile with devtools: long tasks, layout thrashing, large DOM.
- [x] Check MutationObserver in app.js (observes entire body subtree) and per-swap applyNsfw loops.
- [x] Consider debouncing/throttling NSFW re-application.
- [x] Check backdrop-filter blur on sticky header cost.

## Acceptance criteria
- [x] No browser-extension slowdown warning on a typical page.
- [x] Lighthouse/perf budget passes for index and creator pages.

## Resolution

What was slow and what changed:

| Cause | Fix |
|---|---|
| `MutationObserver` on the whole body subtree, firing on every DOM change | Observer removed entirely |
| `applyNsfw()` walking every `img.thumb` on every mutation and every htmx swap | The blur is now a CSS custom property on `<html>` (`--thumb-filter`), so swapped-in images are covered with no JavaScript |
| `backdrop-filter: blur(12px)` on the sticky header | Removed; the header is opaque |
| `backdrop-filter: blur(8px)` on the sticky link-group header | Removed |
| The debug panel rewriting its whole log four times a second | It now appends one node per second, and only while the panel is open |
| The elapsed counter rewriting the DOM twice a second | Once a second, and only when the text actually changed |
| `content-visibility: auto` on post rows | Removed again: a speculative win, and `contain-intrinsic-size` is a source of relayout churn in patched Gecko builds (Zen) |

Measured in Firefox on the creator page (40-post archive): **0 long tasks**
(`PerformanceObserver` `longtask`), 937 DOM nodes, thumbnails blurred by
default.

**DOM mutations per 5 s of idling** (the input every ad blocker's
`MutationObserver` reacts to):

| Page | Before | After |
|---|---|---|
| index | ~19 | ~1 |
| creator | ~19 | ~1 |
| links | ~19 | ~1 |

With `?quiet=1` (no debug capture, no live progress stream, no timers) the
page produces **0** mutations.

The extension warning itself could not be reproduced here (no uBlock/Proton
Pass in the test browser), and Lighthouse is not runnable offline; the
remaining paint cost is a plain HTML page with 21 lazily loaded thumbnails.
Regression tests: `tests/test_debug_ux.py::test_no_backdrop_filter_on_sticky_elements`,
`::test_no_mutation_observer_scans_the_document`,
`::test_thumbnail_blur_is_css_driven`,
`::test_page_does_not_watch_the_dom`,
`::test_dom_writes_only_happen_when_the_value_changes`,
`::test_quiet_mode_is_available`.
